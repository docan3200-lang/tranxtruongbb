CẬP NHẬT LINK THIỆP BẠN BÈ HIỆN CÓ
Giải nén rồi tải đè index.html vào repository đang chạy thiệp bạn bè.

TẠO LINK GITHUB PAGES RIÊNG
1. Giải nén ZIP.
2. Tạo repository mới trên GitHub, ví dụ thiep-moi-ban-be, chọn Public.
3. Chọn Upload files. Tải toàn bộ nội dung đã giải nén lên:
   index.html, style.css, friends.css, script.js, intro.css, intro.js,
   thư mục assets và .nojekyll. Sau đó Commit changes.
   index.html nằm ngay ngoài cùng repository. Không tải nguyên file ZIP.
4. Settings > Pages > Source: Deploy from a branch.
   Branch: main. Folder: /(root). Save.
5. Chờ triển khai xong, mở link trong Pages và gửi khách.
